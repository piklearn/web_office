# سایت دفتر - راهنمای راه‌اندازی

پروژه جنگو شامل سه اپ:
- **main**: صفحه اصلی سایت (معرفی، پشتیبانی فوری، پیگیری سریع، درباره ما، تماس)
- **support (پشتیبانی)**: ثبت و پیگیری کیس‌های تعمیر با کد پیگیری بر اساس شماره تماس مشتری
- **sales (فروش)**: مدیریت کالاها، واحدهای پول (تومان/دلار/درهم/هر ارز دیگر)، ویژگی‌های کالا، و صفحات لیست/جزئیات کالا

## نصب و راه‌اندازی

```bash
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

pip install -r requirements.txt

python3 manage.py migrate
python3 manage.py createsuperuser
python3 manage.py runserver
```

سپس سایت در آدرس http://127.0.0.1:8000 و پنل ادمین در http://127.0.0.1:8000/admin در دسترس است.

## اولین قدم بعد از نصب

1. وارد پنل ادمین شوید.
2. از بخش «تنظیمات سایت» (main → SiteSettings): نام سایت، لوگو، آدرس، تلفن، شماره پشتیبانی فوری،
   متن‌های صفحه اصلی و درباره‌ی ما را وارد کنید. این تنظیمات همان لحظه در کل سایت اعمال می‌شود.
3. از بخش «پشتیبانی → کیس‌های تعمیر»، سیستم/کیس‌های دریافتی از مشتریان را ثبت کنید.
   کد پیگیری به‌صورت خودکار از روی شماره تماس مشتری ساخته می‌شود.
4. مشتری می‌تواند از صفحه اصلی، بخش «پیگیری سریع»، با شماره تماس یا کد پیگیری، وضعیت کیس خود را ببیند.

## بخش فروش (sales)

1. از پنل ادمین، بخش «فروش → واحدهای پول» را باز کنید و واحدهای مورد نیاز (تومان، دلار، درهم یا هر واحد دلخواه دیگر)
   را با نرخ برابری‌شان نسبت به تومان تعریف کنید. برای خودِ تومان مقدار نرخ را ۱ بگذارید.
   **در حال حاضر نرخ‌ها به‌صورت دستی وارد می‌شوند**؛ گزینه‌ی دریافت خودکار آنلاین برای توسعه‌ی بعدی
   در نظر گرفته شده (فایل `sales/services.py` را ببینید — نمونه‌ی پیاده‌سازی و توضیح کامل در همان فایل هست).
2. در بخش «فروش → دسته‌بندی‌ها» (اختیاری) دسته‌های کالا را بسازید.
3. در بخش «فروش → کالاها» کالای جدید اضافه کنید: نام، کد کالا (SKU)، قیمت، واحد قیمت، تصویر،
   توضیح کوتاه و کامل، و موجودی انبار. در همان صفحه، پایین فرم، می‌توانید ویژگی‌های کالا
   (مثلاً رنگ، وزن، گارانتی) را به‌صورت ردیف‌های عنوان/مقدار اضافه کنید.
4. لیست کالاها در آدرس `/shop/` و جزئیات هر کالا در `/shop/<اسلاگ-کالا>/` نمایش داده می‌شود.
   لیست کالاها امکان جستجو و فیلتر بر اساس دسته‌بندی را هم دارد.

## نکات فنی

- طراحی با Tailwind CSS (از طریق CDN) و فونت وزیرمتن (Vazirmatn) پیاده‌سازی شده و کاملاً راست‌به‌چپ (RTL) است.
- رنگ اصلی: آبی و زرد؛ قابل تغییر در فایل `templates/base.html` بخش `tailwind.config`.
- انیمیشن ادمک (چشم‌هایی که موس را دنبال می‌کنند) در فایل `static/js/mascot.js` قرار دارد.
- انیمیشن‌های اسکرول با کلاس `reveal` و IntersectionObserver در `templates/base.html` پیاده شده‌اند.
- طراحی کاملاً واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ است.
- برای ثبت کیس از طریق فرم وب (به‌جای پنل ادمین) آدرس `/support/register/` در دسترس است (نیاز به ورود کارمند دارد).

## نکات امنیتی قبل از انتقال به سرور واقعی (Production)

- مقدار `SECRET_KEY` در `config/settings.py` را تغییر دهید.
- `DEBUG = False` را در `config/settings.py` تنظیم کنید.
- مقدار `ALLOWED_HOSTS` را به دامنه واقعی سایت محدود کنید.
- برای فایل‌های استاتیک/مدیا از یک وب‌سرور مناسب (Nginx و ...) یا سرویس ابری استفاده کنید.
